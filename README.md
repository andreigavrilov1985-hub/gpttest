# Острова Знаний

Обучающая веб-игра для детей (Year 6–10): 5 островов × 5 городов-предметов, 1050 вопросов,
котёнок-проводник. Интерфейс на русском, английский и аудирование на английском.
Статический сайт без сервера и без сборки, работает как PWA (офлайн после первой загрузки).

## Запуск локально

```bash
python3 -m http.server 8080
# открыть http://127.0.0.1:8080/
```

## Структура

| Путь | Что это |
|---|---|
| `index.html`, `css/`, `js/`, `fonts/`, `icons/` | игра |
| `data/*.json` | банки вопросов, по файлу на предмет и остров (`math-island1.json` …) |
| `notion-raw/*.md` | исходный текст 25 страниц Notion, как его вернул Notion MCP |
| `tools/parse_banks.py` | парсер `notion-raw` → `data` с проверкой (10 вопросов в теме, 3 варианта, один ✅, есть «Почему») |
| `tools/build_sw.py` | генерирует `sw.js` (список офлайн-кэша и версия) |
| `tools/make_icons.mjs` | рисует иконки PWA из SVG-котёнка |
| `tests/island1.test.mjs` | автотест этапа 1 (Playwright) |
| `reports/parser-report.md` | таблица парсера по 25 страницам |
| `reports/remarks.md` | замечания к вопросам для Андрея |
| `docs/screenshots/` | скриншоты 360×800 и десктоп |

## Команды

```bash
python3 tools/parse_banks.py   # пересобрать data/*.json и отчёт (код выхода 1 при ошибках)
python3 tools/build_sw.py      # после любого изменения файлов игры
node tests/island1.test.mjs    # автотест (сервер должен работать на 127.0.0.1:8080)
```

Обновить банки из Notion: заново получить страницы через Notion MCP, сохранить их текст
в `notion-raw/<id>.md` (`tools/extract_notion_raw.py` достаёт его из журнала MCP-вызовов),
затем запустить парсер.

## Правила игры (этап 1)

- Ребёнка ведут по порядку: остров 1 → города (математика, английский, наука, география, логика) → темы.
- Перед темой короткие экраны объяснения; из вопроса можно вернуться к объяснению.
- Варианты A/B/C перемешиваются при каждом показе; правильный ответ хранится индексом.
- Город пройден при ≥ 70 % по сумме его вопросов. Если меньше, даются дополнительные задания
  по слабым темам (те же вопросы в новом порядке: запасных банков пока нет).
- Остров 2 открывается только после всех пяти городов острова 1.
- Аудирование: Web Speech API, голос en-GB если есть. Текст не показывается, «Повторить» без ограничений.
  Если голоса нет, игра так и говорит и даёт пропустить тему без штрафа.
- Прогресс только в localStorage этого браузера; в настройках: сброс, сохранение в файл, загрузка из файла.
- Константы (порог 70 %, порог «слишком быстро» для этапа 2) в `js/config.js`.
